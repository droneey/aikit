This repository is Droneey AIkit. The plugin set is defined once, in `templates/project-settings.json`: `install.sh` reads it and the README table describes it. A change to the set updates the README table in the same change, and adds a line to `CLAUDE.skills.md` when two skills overlap. `bun run check` passes before the change is handed back. The images in `.github/assets` — the banner, the heading mark, the badges — are drawn by droneey/brand: change them there, run `bun run render`, and copy `.brand/aikit/` here; never edit them by hand.
