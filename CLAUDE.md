This repository is Droneey AIkit. The plugin set is defined once, in `templates/project-settings.json`: `install.sh` reads it and the README table describes it. A change to the set updates the README table in the same change, and adds a line to `CLAUDE.skills.md` when two skills overlap. `bun run check` passes before the change is handed back. The README images in `.brand/` — the banner, the heading mark, the badges — are drawn from `brand.yml` by the `brand` tool of droneey/brand: edit `brand.yml`, run `brand render`, and commit both; never edit the images by hand.
